1. 설치

run.bat 을 더블클릭하면 설치가 자동으로 진행되고, 끝나면 프로그램이 바로 열려요.
  • 폴더를 원하는 곳에 두고 run.bat 실행 (압축 파일이면 압축 풀고)
  • 처음 한 번만 몇 분 걸려요. 파이썬이 없으면 자동 설치 (관리자 권한 필요 없음)
  • 다음부터는 run.bat 만 누르면 바로 열려요
막히면해결
파란 창 "PC를 보호했습니다"[추가 정보] → [실행]
[ERROR] Python installation failedpython.org/downloads 에서 설치 (Add python.exe to PATH 체크) → run.bat 다시
[ERROR] Could not download / Library installation failed인터넷 확인 → run.bat 다시
설치 후 이상하게 꺼짐.venv 폴더 삭제 → run.bat 다시

3. 등록 방법

처음 한 번만 하면 돼요. 치지직은 내 앱을 직접 등록해서 Client ID · Secret 을 받아야 해요.

① 치지직 개발자 센터에서 앱 등록

developers.chzzk.naver.com → 네이버 로그인 → 애플리케이션 등록

등록이 끝나면 앱 화면에 Client ID 와 Client Secret 이 나와요. Secret 은 비밀번호예요 — 남에게 보여주거나 방송 화면에 띄우지 마세요.

② 프로그램에 키 넣기

프로그램 맨 위 [설정] → 키 · ID · 서버 주소 → 입력 → [저장]

칸넣을 것
필수 Client ID · Secret①에서 받은 값
필수 채널 ID내 방송국 주소 chzzk.naver.com/ 뒤 32자리
선택 스팀 API 키 · SteamID64스팀 게임 감지용 — steamcommunity.com/dev/apikey (도메인: localhost), 프로필 · 게임 세부 정보 공개
선택 유튜브 API 키 · 방송 주소유튜브 채팅용 — Google Cloud → YouTube Data API v3 → API 키

③ 치지직 로그인

맨 위 [치지직 로그인] → 브라우저에서 동의 → "치지직 계정 연동 완료!" 가 나오면 끝

✔ 맨 위 딱지가 로그인됨(초록)으로 바뀌고, 채팅 위에 ● 연결됨 — 다음부터는 run.bat 만 켜면 자동 로그인 (30일 넘게 안 쓰면 다시)
권한을 나중에 바꿨다면 [방송] → 로그아웃 → 다시 로그인해야 적용돼요.

4. 사용법

방송할 때는 run.bat 만 켜 두면 채팅 · 후원 · 미션이 자동으로 들어와요. (꺼져 있던 동안의 후원은 못 가져와요)

하고 싶은 일 → 어디서?

이럴 때여기로
방송 제목 바꾸기[방송] → 방송 관리 → ① 제목
카테고리 바꾸기[방송] → 방송 관리 → ② 카테고리 → 검색 → [카테고리 적용]
카테고리 자동 변경방송 관리 → ② '게임이 바뀌면 자동으로 맞추기' 체크 + 맨 위 [자동] 체크
채팅 보내기 · 공지[방송] → 방송 관리 → 채팅 · 공지
도배 시청자 막기채팅에서 닉네임 클릭 → 임시 제한 / 활동 제한 / 메시지 가리기
유튜브 채팅 같이 보기[설정]에 API 키 · 방송 주소 저장 → 채팅 위 [유튜브 연결] (끝나면 [유튜브 끊기])
게임 감지가 이상할 때[보기] → 방송 상태 (감지 결과) · [보기] → 게임 짝 (짝 추가 · 수정)

후원

하고 싶은 일방법
영상 후원 대기열로 쓰기후원 목록 보기: 영상 후원만 + □ 대기만 보기 → 본 영상은 줄 더블클릭(대기 ↔ 봄) 또는 [봄 표시] / [넘김 표시]
영상 재생 · 건너뛰기[치지직 스튜디오 열기] — 치지직 API 에 제어 기능이 없어서 스튜디오에서
후원이 들어오는지 확인[테스트 도구] → 연결 점검 → 4줄 모두 [성공] / 치지직 스튜디오의 테스트 후원으로 목록 확인
기록data/donations.json 에 자동 저장 (최근 3000건) · [목록 지우기] 는 기록까지 삭제

미션

하고 싶은 일방법
자동 등록후원 메시지가 "미션" 으로 시작 (예: 미션: 노데스로 보스 잡기, [미션] 30분 안에 클리어)
직접 등록후원 목록 [미션으로 만들기] / 미션 칸 [미션 추가...]
타이머[시작 / 재개] · [-1분] [+1분] · 시간 끝 → '시간 초과' + 소리 → [성공] [실패] [거절]
설정미션 칸 [설정 열기] — 기본 제한 시간 · 자동 등록 단어 · 소리 · 채팅 알림(시작 · 결과)
OBS 에 타이머 띄우기설정 → 'OBS 용 타이머 파일 쓰기' → [경로 복사] → OBS 소스 [+] → 텍스트(GDI+) → '파일에서 읽기' → 그 경로
