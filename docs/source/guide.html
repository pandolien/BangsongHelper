1. 설치하기

  • 준비물: Windows 10 / 11, 인터넷 (처음 설치할 때만)
  • 파이썬: 없어도 됨 → Python 3.12 자동 설치 (관리자 권한 필요 없음)

설치 순서

  1. BangsongHelper 폴더를 원하는 곳에 두기 (압축 파일이면 압축 풀기) — 예: D:\BangsongHelper
  2. install.bat 더블클릭 (처음 한 번만, 몇 분 걸림)
  3. Setup complete 나오면 설치 끝
  4. run.bat 더블클릭 → 프로그램 실행 (설치 전에 눌러도 설치부터 진행됨) → 3장으로
[1/4] Looking for Python...                    ← 파이썬 찾기
[2/4] Installing Python 3.12.10 ...            ← 없을 때만 자동 설치
[3/4] Preparing virtual environment (.venv)... ← .venv 폴더 만들기
[4/4] Installing libraries...                  ← 라이브러리 설치
Setup complete. Now run run.bat

4. 게임 ↔ 카테고리 자동 연동

  • 게임 켜면 치지직 카테고리 자동 변경
  • 스팀 · 치지직 게임 이름이 달라서 게임마다 짝 저장 (예: ELDEN RING NIGHTREIGN = ELDEN RING 밤의 통치자)

방송 관리 창

  • 지금 방송 설정: 제목 · 카테고리 · 태그
  • ① 제목: 새 제목 → [제목 적용]
  • ② 카테고리: [지금 게임으로 맞추기] 또는 검색 → [카테고리 적용]
  • 채팅 · 공지: 채팅 보내기 · 공지 등록

자동 변경 켜기

  1. 방송 관리 → ② → '게임이 바뀌면 자동으로 맞추기' 체크
  2. 메인 화면 맨 위 [자동] 체크
주의: 켜 두면 프로그램 시작 즉시 카테고리가 바뀔 수 있음 → 다른 방송 때는 끄기

게임 감지 방법

방법내용

  • '지금 하는 게임' 칸: 감지된 게임 + 치지직 짝

짝이 없을 때 — 자동 찾기

  1. 스팀 상점 한국어 이름으로 검색 (TEKKEN 8 → 철권 8)
  2. 내장 한국어 이름 목록(약 115개)으로 검색 (Counter-Strike 2 → 카운터 스트라이크 2)
  3. 이름이 똑같은 카테고리 → 짝 저장 + 바로 적용
  4. 못 찾음 → '종합 게임' (짝 저장 안 함, ②의 체크박스로 끄고 켜기)
기본 짝 105개 포함 (스팀 동시접속 상위 100개 중 89개 + 스팀 밖 인기 게임)

짝 직접 만들기 · 고치기

  • [방송] → 지금 게임으로 카테고리 맞추기: 못 찾으면 후보 + '종합 게임' 중 선택 → [카테고리 적용] → 짝 자동 저장
  • [보기] → 게임 짝: [지금 하는 게임] / [실행 중인 프로그램에서] → 카테고리 검색 → [짝 저장]
    • 줄 클릭 = 수정 · [선택한 짝 삭제] = 삭제

6. 유튜브 채팅 같이 보기

  • 치지직 + 유튜브 동시 송출 시 유튜브 채팅을 [YT] 로 섞어 표시
  • 유튜브 공식 Data API 사용 — 구글 로그인 불필요, API 키만 필요

API 키 발급 (한 번만, 무료)

  1. console.cloud.google.com 로그인 → 새 프로젝트
  2. API 및 서비스 → 라이브러리 → YouTube Data API v3 → 사용
  3. API 및 서비스 → 사용자 인증 정보 → 만들기 → API 키 → 복사
  4. (권장) 키 → API 제한사항 → YouTube Data API v3 만 허용
  5. [설정] → 키 · ID · 서버 주소 → 유튜브 → API 키 붙여넣기 → [저장]

연결하기 NEW

  1. [설정] → 유튜브 → 방송 주소 입력 (예: https://www.youtube.com/live/xxxxxxxxxxx) → [저장]
  2. 채팅 위 [YT] 줄 → [유튜브 연결] (같은 줄에 상태 · 오늘 사용량 표시)
  • 슈퍼챗: 노란 줄 + 후원 목록('유튜브') · "미션"으로 시작하면 미션 등록
  • 연결 유지: [유튜브 끊기] 또는 프로그램 끌 때까지 → 방송 끝나면 끊기 (사용량 절약)
  • @채널이름 도 가능 — 단, 찾을 때 100점 사용 → 방송 주소 권장
  • 유튜브로 채팅 보내기는 안 됨
하루 사용량
  • 프로젝트당 하루 10,000점 / 채팅 한 번 가져올 때 5점 / 한국 시간 오후 4~5시 초기화
  • [설정] → 채팅 가져오는 간격 (기본 8초 ≈ 하루 약 4시간)
  • 부족하면 Google Cloud 에서 할당량 증가 신청 (무료)

8. 미션 & 타이머

  • 메인 화면 오른쪽 아래
  • 치지직 API 에 '미션 후원' 이 없어서 → 들어오는 후원에서 골라냄

미션 등록

  • 자동: 후원 메시지가 "미션"으로 시작 — 예) 미션: 노데스로 보스 잡기, [미션] 30분 안에 클리어
  • 직접: 후원 목록 [미션으로 만들기] / 미션 칸 [미션 추가...]

타이머

  • [시작 / 재개] · [일시정지] · [-1분] [+1분] · 더블클릭 = 시작 ↔ 일시정지
  • 시간 끝 → '시간 초과' + 소리 → [성공] [실패] [거절]로 마무리 (+1분 누르면 다시 진행)
  • 채팅 위에 진행 중 타이머 항상 표시 · data/missions.json 저장 (타이머도 이어짐)

  3. 미션 시작 → [미션] 노데스로 보스 잡기 - 후원자C 07:17 1초마다 갱신
