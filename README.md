# chzzkControl

스팀 · 치지직 방송 상태를 보여주고, 방송 제목 · 카테고리 변경, 채팅, 후원 · 미션 관리를 할 수 있는 프로그램입니다.

---

## 1. 설치 방법

### 방법 A — exe 로 쓰기 (파이썬 필요 없음)

1. `chzzkControl` 폴더(압축 파일)를 받아서 원하는 곳에 풉니다.
2. 폴더 안의 `chzzkControl.exe` 를 실행합니다.

### 방법 B — 소스 코드로 쓰기

1. 이 저장소를 내려받습니다.
2. `run.bat` 을 더블클릭합니다.
   - 처음 한 번은 파이썬(없으면 자동 설치) → 가상환경(`.venv`) → 라이브러리 설치가 진행됩니다.
   - 설치만 따로 하려면 `install.bat` 을 실행하세요.

### exe 직접 만들기

`build_exe.bat` 실행 → `dist\chzzkControl\` 폴더에 exe 가 만들어집니다. 이 폴더를 통째로 압축해서 나눠 주면 됩니다.

---

## 2. 사용 방법

### 처음 설정 (한 번만)

프로그램의 **[설정]** 탭에 아래 값을 넣고 **저장**합니다.

| 항목 | 받는 곳 |
|---|---|
| 스팀 API 키 | <https://steamcommunity.com/dev/apikey> (도메인 칸에 `localhost`) |
| SteamID64 | 스팀 프로필 주소 뒤의 17자리 숫자 (프로필 · 게임 세부 정보를 **공개**로) |
| 치지직 Client ID / Secret | <https://developers.chzzk.naver.com> → 애플리케이션 등록<br>로그인 리디렉션 URL: `http://localhost:8080/callback` |
| 치지직 채널 ID | 내 방송국 주소 `chzzk.naver.com/` 뒤의 32자리 |
| 유튜브 API 키 (선택) | <https://console.cloud.google.com> → `YouTube Data API v3` 사용 → API 키 만들기 |

그다음 **[방송 관리] → 치지직 로그인** 을 눌러 브라우저에서 동의하면 제목 · 카테고리 변경, 채팅 기능을 쓸 수 있습니다.

> 치지직 개발자 센터에서 쓰려는 기능의 **API Scope(권한)** 를 체크해야 합니다.
> (방송 설정 변경, 채팅 메시지 조회/쓰기, 채팅 공지, 후원 조회, 활동제한 조회/쓰기)
> 권한을 추가했다면 **로그아웃 → 다시 로그인** 해야 적용됩니다.

### 화면(GUI)

| 탭 / 버튼 | 하는 일 |
|---|---|
| 대시보드 | 스팀 게임 · 방송 상태 · 시청자 수 보기 |
| 대시보드 → 방송 도우미 | 실시간 채팅 + 후원 목록 + 미션을 한 화면에 |
| 방송 관리 | 치지직 로그인, 제목 · 카테고리 변경, 지금 게임으로 카테고리 맞추기 |
| 게임 짝 | 게임 ↔ 치지직 카테고리 짝 보기 · 추가 · 수정 · 삭제 |
| 설정 / URL 설정 | 키 · ID 입력, 서버 주소 변경 |

### 터미널(CLI)

| 명령 | 하는 일 |
|---|---|
| `run.bat status` | 스팀 + 치지직 상태 한 번 출력 |
| `run.bat watch --interval 30` | 30초마다 계속 출력 (Ctrl+C 종료) |
| `run.bat login` / `run.bat logout` | 치지직 계정 연동 / 해제 |
| `run.bat setting` | 내 방송 설정 보기 |
| `run.bat set-title "새 제목"` | 방송 제목 변경 |
| `run.bat set-category "발로란트"` | 카테고리 검색 후 첫 결과로 변경 |
| `run.bat chat "안녕하세요"` | 채팅 전송 (최대 100자) |
| `run.bat notice "공지 내용"` | 채팅 공지 등록 |
| `run.bat sync-game` | 지금 하는 게임으로 카테고리 맞추기 |
| `run.bat game-map` | 게임 짝 목록 보기 |
| `run.bat game-map-add 2622380 "나이트레인" --memo "메모"` | 게임 짝 추가 / 수정 (gameid 자리에 exe 이름도 가능) |
| `run.bat game-map-remove 2622380` | 게임 짝 삭제 |

## 3. 파일 위치

모든 설정 · 기록은 프로그램 폴더 안의 **`data/`** 폴더에 저장됩니다.
(소스로 실행하면 `main.py` 가 있는 폴더, exe 로 실행하면 `chzzkControl.exe` 가 있는 폴더)

| 파일 | 내용 | 공유 |
|---|---|---|
| `data/init.json` | 모든 설정 + API 키 · Secret · 토큰. 저장소에는 **키를 비운 양식**으로 올라가 있음 | ⚠️ 빈 양식만 |
| `data/donations.json` | 받은 후원 기록 (닉네임 · 금액 · 내용) | ❌ |
| `data/missions.json` | 미션 기록 | ❌ |
| `data/youtube_quota.json` | 유튜브 오늘 사용량 | ❌ |
| `data/error.log` | 오류 기록 | ⚠️ 확인 후 |
| `data/mission_timer.txt` | OBS 에 띄우는 미션 타이머 (1초마다 갱신) | — |
| `data/game_map.txt` | 게임 ↔ 치지직 카테고리 짝 목록 | ✅ 가능 |
| `docs/chzzkControl_정리.pdf` | 그림으로 보는 사용 안내서 | ✅ 가능 |

> **주의:** 키를 넣거나 치지직 로그인을 하면 `data/init.json` 에 진짜 키 · 토큰이 저장됩니다.
> 그대로 `git add .` 하면 깃허브에 올라가니, 키를 넣은 뒤 한 번 아래 명령을 실행해 두세요. (이 PC 에서 이 파일 변경을 무시)
>
> ```
> git update-index --skip-worktree data/init.json
> ```

### 소스 코드 구성

```
chzzkControl/

├─ config_manager.py        data/init.json 읽기 · 쓰기

├─ steam/                   스팀 API
├─ chzzk/                   치지직 API · 로그인 · 실시간 채팅

├─ gui/                     화면 (메인 · 채팅 · 후원 · 미션 · 방송 도우미 · 테스트 도구)
└─ install.bat / run.bat / build_exe.bat
```

## 4. 기능

- **상태 보기** — 스팀에서 하는 게임, 치지직 방송 켜짐 여부 · 제목 · 카테고리 · 시청자 수 (자동 새로고침)
- **방송 설정 변경** — 방송 제목 · 카테고리 변경, 채팅 전송, 채팅 공지 등록
- **카테고리 자동 맞추기** — 지금 하는 게임(스팀 또는 실행 중인 프로그램)으로 치지직 카테고리 자동 변경
  - 짝 목록에 인기 게임 105개 기본 포함, 없으면 한국어 이름으로 자동 검색, 그래도 없으면 '종합 게임'
  - 스팀 밖 게임(롤 · 발로란트 · 메이플 등)도 감지, 게임이 아닌 스팀 프로그램(Wallpaper Engine, OBS 등)은 무시
- **방송 도우미** — 실시간 채팅 + 후원 목록 + 미션을 한 창에서, 항상 위 고정 가능
- **실시간 채팅** — 스트리머 · 매니저 표시, 닉네임 색, 후원 강조, 자동 재연결, 바로 채팅 보내기
- **시청자 관리** — 임시 제한 / 활동 제한 / 메시지 가리기 / 제한 목록에서 풀기
- **후원 목록** — 영상 · 채팅 후원 모아 보기, 대기 / 봄 / 넘김 표시, 합계, 껐다 켜도 기록 유지
- **미션** — "미션"으로 시작하는 후원 자동 등록, 타이머(시작 · 일시정지 · ±1분), 시간 초과 알림, OBS 용 타이머 파일, 채팅 알림
- **유튜브 채팅 같이 보기** — 동시 송출 시 유튜브 채팅을 `[YT]` 로 섞어 보기, 슈퍼챗은 후원 · 미션으로
- **테스트 도구** — 가짜 후원 · 채팅 보내기, 실패 상황 흉내, 실제 연결 단계별 점검
