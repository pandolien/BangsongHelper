# chzzkControl — 스팀 + 치지직 상태 조회/제어 도구

스팀에서 **지금 무슨 게임을 하는지**, 치지직 방송이 **켜져 있는지 / 제목·카테고리·시청자 수**를 실시간으로 보여주고,
로그인하면 **방송 제목·카테고리 변경, 채팅 전송, 공지 등록**까지 할 수 있는 프로그램입니다.

## 폴더 구조

```
chzzkControl/
├─ run.bat               ← 더블클릭하면 실행 (가상환경/라이브러리 자동 준비)
├─ main.py               ← 시작점: 인자 없으면 GUI, 있으면 CLI
├─ main_cli.py           ← 터미널 명령 모음
├─ config_manager.py     ← data/init.json 읽기/쓰기, 토큰 저장
├─ game_map.py           ← data/game_map.txt (게임 짝) 읽기/쓰기
├─ install.bat           ← 파이썬 → .venv → 라이브러리 자동 설치
├─ data/init.json        ← 모든 설정값 + API URL (처음 실행 시 자동 생성)
├─ data/init_upload.json ← 개인정보(키 · ID · 토큰)를 뺀 업로드용 설정 (깃허브 등에 올리는 파일)
├─ steam/steam_api.py    ← 스팀 Web API (GetPlayerSummaries)
├─ youtube/youtube_api.py ← 유튜브 공식 Data API (라이브 채팅 읽기)
├─ youtube/youtube_chat.py ← 유튜브 채팅 계속 가져오기 + 오늘 사용량 기록
├─ gui/youtube_hub.py    ← 유튜브 채팅 → 화면 (슈퍼챗은 후원 · 미션으로)
├─ chzzk/chzzk_api.py    ← 치지직 API (조회/방송설정/채팅/토큰)
├─ chzzk/chzzk_auth.py   ← 치지직 브라우저 로그인 (localhost 콜백 서버)
├─ chzzk/chzzk_session.py ← 치지직 실시간 채팅 받기 (Socket.IO)
├─ game_detect.py        ← 스팀 밖 게임 감지 (실행 중인 프로그램)
├─ category_match.py     ← 게임 → 치지직 카테고리 자동 짝 찾기 (스팀 한국어 이름 · 한국어 이름 목록 · 종합 게임)
├─ gui/chat_hub.py       ← 실시간 채팅 연결 공유 (채팅창 · 후원 목록 창)
├─ gui/chat_window.py    ← 실시간 채팅창
├─ gui/donation_window.py ← 후원 목록 창 (영상 후원 관리)
├─ gui/restrict_dialog.py ← 활동 제한 목록 창
├─ gui/bg_task.py        ← 뒤에서 일하는 일꾼 (창들이 같이 씀)
├─ gui/test_dialog.py    ← 테스트 도구 (가짜 후원 · 실패 흉내 · 연결 점검)
├─ gui/mission_window.py ← 미션 화면 (미션 받기 + 타이머 + OBS 타이머 파일)
├─ gui/stream_window.py  ← 방송 도우미 창 (채팅 + 후원 목록 + 미션을 한 화면에)
└─ gui/main_window.py    ← PySide6 화면
```

## 실행 방법

1. 프로그램을 실행한 뒤 **[설정]** 탭에서 키를 입력하고 **저장**합니다. → `data/init.json` 에 저장됩니다.
   (처음 실행하면 `data/init.json` 이 기본 양식으로 자동 생성되니, 파일을 직접 열어 채워도 됩니다.)
2. `run.bat` 을 더블클릭합니다. 처음 한 번은 라이브러리(requests, PySide6)를 설치하느라 시간이 걸립니다.

터미널에서 쓰고 싶으면:

| 명령 | 하는 일 |
|---|---|
| `run.bat status` | 스팀 + 치지직 상태 한 번 출력 |
| `run.bat watch --interval 30` | 30초마다 계속 출력 (Ctrl+C 종료) |
| `run.bat login` / `run.bat logout` | 치지직 계정 연동 / 해제 |
| `run.bat setting` | 내 방송 설정 보기 |
| `run.bat set-title "새 제목"` | 방송 제목 변경 |
| `run.bat set-category "발로란트"` | 카테고리 검색 후 첫 결과로 변경 |
| `run.bat chat "안녕하세요"` | 채팅 전송 (최대 100자) |
| `run.bat notice "공지 내용"` | 채팅 공지 등록 |
| `run.bat sync-game` | 지금 하는 게임(스팀 또는 실행 중인 프로그램)으로 치지직 카테고리 맞추기 (짝이 없으면 골라서 저장) |
| `run.bat game-map` | 게임 짝 목록 보기 |
| `run.bat game-map-add 2622380 "나이트레인" --memo "ELDEN RING NIGHTREIGN"` | 게임 짝 직접 추가/수정. gameid 자리에 `VALORANT-Win64-Shipping.exe` 같은 프로그램 이름도 됨 |
| `run.bat game-map-remove 2622380` | 게임 짝 삭제 |

> **주의:** `data/init.json` 에는 비밀 키와 토큰이 들어갑니다. **절대 공유하거나 깃허브에 올리지 마세요.** (`.gitignore` 에 이미 등록됨)
>
> 업로드할 때는 `data/init_upload.json` 을 쓰세요. 키 · ID · 토큰이 빈칸인 파일이며, URL 을 바꿨다면
> `run.bat make-upload-config` 로 다시 만들 수 있습니다. 새 컴퓨터에서 `init.json` 이 없으면
> 이 파일을 양식으로 삼아 자동으로 만들어집니다. (자동 카테고리 변경은 꺼진 상태로 저장)

## API 키 발급 및 설정 방법

### 1. 스팀 Web API 키 (`steam.api_key`)

1. <https://steamcommunity.com/dev/apikey> 에 스팀 계정으로 로그인합니다.
2. **도메인 이름** 칸에 아무 이름(예: `localhost`)을 적고 약관에 동의 → **등록**.
3. 화면에 나온 32자리 키를 `steam.api_key` 에 넣습니다.
   - 스팀 계정에 **5달러 이상 결제 이력**이 없는 '제한된 계정'은 키 발급이 안 될 수 있습니다.
   - 스팀 모바일 인증기(Steam Guard)가 필요할 수 있습니다.

### 2. SteamID64 (`steam.steam_id`)

- 스팀 프로필 주소가 `https://steamcommunity.com/profiles/7656119xxxxxxxxxx` 형태라면 뒤의 **17자리 숫자**가 SteamID64 입니다.
- 주소가 `https://steamcommunity.com/id/내아이디` 형태(사용자 지정 URL)라면, <https://steamid.io> 같은 사이트에 주소를 넣어 `steamID64` 값을 확인하세요.

### 3. 스팀 프로필 공개 설정 (중요!)

게임 정보(`gameid`, `gameextrainfo`)는 프로필이 공개일 때만 내려옵니다.

- 스팀 → 프로필 → **프로필 편집 → 개인 정보 설정**
- **내 프로필: 공개**, **게임 세부 정보: 공개** 로 설정
- 비공개면 프로그램에 "프로필 비공개" 로 표시됩니다.

### 4. 치지직 Client ID / Client Secret (`chzzk.client_id`, `chzzk.client_secret`)

1. <https://developers.chzzk.naver.com> 에 네이버 계정으로 로그인합니다.
2. **애플리케이션 등록**을 누르고 다음을 입력합니다.
   - **애플리케이션 이름**: 아무 이름
   - **로그인 리디렉션 URL**: `http://localhost:8080/callback`
     (`data/init.json` 의 `chzzk.redirect_uri` 와 **글자 하나까지 똑같아야** 합니다.)
   - **API Scope(권한)**: 사용할 기능을 체크합니다.
     - 조회만 할 경우: 채널 조회, 라이브 조회 등
     - 방송 관리: **방송 설정 조회/변경**
     - 채팅: **채팅 메시지 쓰기**, **채팅 공지 등록**
3. 등록(심사가 필요할 수 있음)이 끝나면 **Client ID** 와 **Client Secret** 을 복사해 넣습니다.

### 5. 치지직 채널 ID (`chzzk.channel_id`)

- 내 방송국 주소 `https://chzzk.naver.com/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` 의 뒤쪽 **32자리 영문+숫자**가 채널 ID 입니다.

### 6. 치지직 계정 연동 (방송 관리 기능용)

제목/카테고리 변경, 채팅, 공지는 **방송하는 본인의 허락(Access Token)** 이 필요합니다.

- GUI: **[방송 관리] → 치지직 로그인** 클릭 → 브라우저에서 동의
- CLI: `run.bat login`

동의하면 토큰이 `data/init.json` 에 저장되고, 만료(1일) 시 자동으로 갱신됩니다.
Refresh Token 까지 만료되면 다시 로그인하라는 안내가 뜹니다.

## data/init.json 구조

```json
{
  "steam": { "api_key": "", "steam_id": "" },
  "chzzk": { "client_id": "", "client_secret": "", "channel_id": "",
             "redirect_uri": "http://localhost:8080/callback",
             "access_token": "", "refresh_token": "", "token_expire_at": 0 },
  "urls": {
    "steam": { "player_summaries": "https://api.steampowered.com/ISteamUser/GetPlayerSummaries/v2/" },
    "chzzk": {
      "open_api_base": "https://openapi.chzzk.naver.com",
      "service_api_base": "https://api.chzzk.naver.com",
      "authorize": "https://chzzk.naver.com/account-interlock",
      "live_detail": "/service/v2/channels/{channelId}/live-detail",
      "lives": "/open/v1/lives", "channels": "/open/v1/channels",
      "category_search": "/open/v1/categories/search",
      "token": "/auth/v1/token", "token_revoke": "/auth/v1/token/revoke",
      "live_setting": "/open/v1/lives/setting",
      "chat_send": "/open/v1/chats/send", "chat_notice": "/open/v1/chats/notice",
      "chat_settings": "/open/v1/chats/settings",
      "session_auth": "/open/v1/sessions/auth",
      "session_subscribe_chat": "/open/v1/sessions/events/subscribe/chat",
      "session_subscribe_donation": "/open/v1/sessions/events/subscribe/donation"
    }
  },
  "app": { "refresh_interval_sec": 30, "auto_sync_category": false }

```

- `urls.chzzk` 에서 `*_base`, `authorize` 는 완전한 주소, 나머지는 기본 주소 뒤에 붙는 **경로**입니다.
  (`live_detail` 은 `service_api_base` 뒤, 나머지는 `open_api_base` 뒤)
- 치지직/스팀이 주소를 바꾸면 코드 수정 없이 GUI **[URL 설정]** 탭이나 이 파일만 고치면 됩니다.
- 칸을 비우거나 지우면 프로그램 기본값이 사용됩니다.

## 스팀 게임 ↔ 치지직 카테고리 짝 (data/game_map.txt)

스팀과 치지직은 같은 게임도 이름이 다릅니다. (예: 스팀 `ELDEN RING NIGHTREIGN` / 치지직 `ELDEN RING 밤의 통치자` — 스팀 이름으로 검색하면 0건)
그래서 **스팀 gameid ↔ 치지직 카테고리 ID** 를 짝으로 저장해 둡니다.

```
# 스팀gameid = 카테고리종류 | 카테고리ID | 치지직카테고리이름   # 메모
2622380 = GAME | Elden_Ring_Nightreign | ELDEN RING 밤의 통치자   # ELDEN RING NIGHTREIGN
exe:league of legends.exe = GAME | League_of_Legends | 리그 오브 레전드   # 롤
```

- **스팀 밖 게임**(롤 · 발로란트 · 메이플 등)은 내 PC에서 **실행 중인 프로그램 이름(exe)** 으로 감지합니다.
  스팀에서 게임 중이면 스팀이 먼저, 아니면 실행 중인 프로그램에서 찾습니다. 스팀 API 키가 없어도 이 방식만으로 쓸 수 있습니다.
- 잘 알려진 게임(롤, 발로란트, 메이플스토리, 로스트아크 등)은 짝이 없어도 "감지됨" 으로 보여주고 검색어를 채워 줍니다.
  목록에 없는 게임은 **[게임 짝] → 실행 중인 프로그램에서 고르기** 로 짝을 만드세요.
- 프로그램 감지는 이 프로그램이 켜진 PC 만 볼 수 있습니다. (게임 PC 와 방송 PC 가 다르면 스팀 게임만 감지됨)

- **짝이 없는 게임은 자동으로 찾습니다.** 스팀 상점의 **한국어 이름**(예: TEKKEN 8 → 철권 8)과 내장 **한국어 이름 목록**
  (예: Counter-Strike 2 → 카운터 스트라이크 2, 약 70개)으로 치지직을 검색해서, **이름이 똑같은 카테고리**가 있을 때만 짝으로 저장합니다.
  (인기 게임 40개로 시험해서 38개 자동으로 맞음. 나머지 2개는 치지직에 카테고리가 없는 게임)
- **목록에 없는 스팀 밖 게임도 알아봅니다.** 에픽 · 넥슨 · 엑스박스 · 라이엇 · GOG · 유비 · EA 등 **게임 설치 폴더에서 실행된 프로그램**을
  게임으로 보고, **창 제목**을 게임 이름으로 써서 치지직 카테고리를 자동 검색합니다. (런처 · 업데이트 · 안티치트 프로그램은 제외.
  `[방송 관리]` 의 '목록에 없는 게임도 알아보기' 로 끄고 켜기)
- **게임이 아닌 스팀 프로그램은 무시합니다.** Wallpaper Engine · OBS Studio · Crosshair X · Bongo Cat 등은 스팀에 '플레이 중' 으로 뜨지만
  카테고리를 바꾸지 않고, 실제로 실행 중인 게임을 찾습니다. (목록: `game_detect.py` 의 `DICT_NON_GAME_STEAM_APPS`)
- 짝 목록에는 **스팀 동시접속자 상위 100개 중 89개**(게임이 아닌 4개 · 치지직에 없는 7개 빼고 전부) + 스팀 밖 인기 게임이 미리 들어 있습니다. (총 105개)
- **치지직에 없는 게임은 '종합 게임'** 으로 바꿉니다. (자동 맞추기 때, `[방송 관리]` 의 체크박스로 끄고 켜기. 짝으로 저장하지는 않음)
- GUI **[방송 관리] → 지금 게임으로 맞추기**: 짝이 있으면 바로 적용 → 없으면 자동으로 찾기 → 그래도 없으면 후보 + '종합 게임' 중에서 골라 **[카테고리 적용]** (짝 자동 저장)
- **"스팀 게임이 바뀌면 치지직 카테고리 자동 변경"** 을 켜고 자동 새로고침을 켜 두면 게임을 바꿀 때마다 카테고리가 바뀝니다. (치지직 로그인 필요)
- **[게임 짝]** 탭에서 목록 확인 / 삭제 / 메모장으로 열기. 잘못된 줄은 건너뛰고 로그로 알려줍니다.
- **[게임 짝] → 짝 추가 / 수정**: 스팀 gameid 입력(또는 '지금 하는 스팀 게임 불러오기') → 치지직 카테고리 검색 → 골라서 **짝 저장**. 목록에서 줄을 누르면 그 짝을 고칠 수 있습니다.

## 방송 도우미 (채팅 + 후원 목록 + 미션을 한 화면에)

**[대시보드] → 방송 도우미** 를 누르면 한 화면에 다 나옵니다.

```
┌──────────────── 치지직 방송 도우미 ──────────────────┐
│ 10:00 [미션 진행 중] 노데스 클리어 — A  (항상 보임)    │
├───────────────┬─────────────────────────────────────┤
│               │ 후원 목록 (대기 1)                    │
│  실시간 채팅   ├─────────────────────────────────────┤
│               │ 미션 (1)                [설정 열기]   │
└───────────────┴─────────────────────────────────────┘
```

- 왼쪽 **실시간 채팅** (연결 상태 · [연결] 버튼도 여기), 오른쪽 위 **후원 목록**, 오른쪽 아래 **미션** — 탭 없이 한 번에 다 보입니다.
- 경계선(가운데 세로 · 오른쪽 가로)을 끌어서 크기 조절. 미션 설정은 **[설정 열기]** 로 접고 폅니다.
- 맨 위에는 진행 중인 미션 타이머가 항상 보입니다.
- 채팅의 **항상 위** 를 켜면 창 전체가 다른 창 위에 떠 있습니다.
- 대시보드 버튼에 `방송 도우미 (대기 2 · 미션 1)` 처럼 숫자가 표시됩니다.

## 실시간 채팅

**방송 도우미** 왼쪽이 실시간 채팅입니다. 창을 열면 로그인돼 있을 때 바로 연결됩니다.

- 스트리머 / 매니저 딱지, 닉네임별 색깔, 후원은 노란 줄로 표시
- 항상 위, 자동 스크롤(위로 올려서 보는 중엔 안 내려감), 시간 표시, 글자 크기, 지우기
- 아래 입력칸에서 바로 채팅 보내기 (100자)
- 연결이 끊기면 3초 → 6초 → … 최대 60초 간격으로 자동 재연결, 창을 닫으면 연결 종료
- 이모티콘은 그림 대신 회색 `[이름]` 으로 표시됩니다.

**필요한 권한 (개발자 센터 → API Scope):** `채팅 메시지 조회` (필수), `후원 조회` (후원 알림을 보려면).
권한을 추가했다면 프로그램에서 **로그아웃 → 다시 로그인** 해야 적용됩니다.
치지직 채팅은 Socket.IO 2.x 방식이라 `python-socketio` 4.x 버전으로 고정해 두었습니다.

## 시청자 관리 (임시 제한 · 활동 제한 · 메시지 가리기)

채팅창에서 **닉네임을 누르거나 채팅 줄을 우클릭**하면 메뉴가 뜹니다.

| 메뉴 | 하는 일 |
|---|---|
| 임시 제한 | 잠깐 채팅 금지. 시간은 치지직이 정함 (처음 30초, 또 하면 60초 …) |
| 임시 제한 풀기 | 임시 제한 해제 |
| 이 메시지 가리기 | 그 채팅 한 줄을 가림 |
| 활동 제한 (풀 때까지) | 확인 후 제한. 채팅창의 **[제한 목록]** 에서 보고 풀 수 있음 |
| 닉네임 복사 | 닉네임을 클립보드로 |

- 스트리머 본인 채팅에는 제한 메뉴가 나오지 않습니다.
- **필요한 권한 (개발자 센터 → API Scope):** `활동제한 쓰기`, `활동제한 조회`, `채팅 메시지 쓰기`(가리기)
  권한을 추가했다면 프로그램에서 **로그아웃 → 다시 로그인** 해야 적용됩니다.
- 임시 제한은 금방 풀려서 치지직이 목록을 주지 않습니다. [제한 목록] 에는 활동 제한만 나옵니다.

## 미션 (미션 받기 + 타이머)

**[대시보드] → 방송 도우미** 오른쪽 아래 (창을 안 열어도 미션은 자동 등록됨)
창 맨 위에는 진행 중인 미션 타이머가 항상 보입니다.

치지직 공식 API 는 '미션 후원' 을 따로 알려주지 않아서, 들어오는 후원에서 미션을 골라냅니다.

- **자동 등록**: 후원 메시지가 **`미션`** 으로 시작하면 미션으로 등록 (예: `미션: 노데스로 보스 잡기`, `[미션] 30분 안에 클리어`). 시작 단어는 바꿀 수 있음
- **직접 등록**: 후원 목록에서 고르고 **[미션으로 만들기]**, 또는 미션 창 **[미션 추가]**
- **타이머**: 시작 / 일시정지 / +1분 · -1분. 맨 위에 **큰 카운트다운**, 끝나면 **'시간 초과'** + 소리 → 성공 / 실패 / 거절로 마무리
- **방송 화면 타이머**: `data/mission_timer.txt` 를 1초마다 갱신합니다.
  OBS → 소스 추가 → **텍스트(GDI+)** → **'파일에서 읽기'** 체크 → 이 파일 선택 (미션 창의 [경로 복사] 버튼)
- **채팅 알림** (선택): 미션 시작 · 성공 · 실패 · 시간 초과를 채팅으로 보냄
- 미션은 `data/missions.json` 에 저장돼서 다시 켜도 남고, 진행 중이던 타이머도 이어집니다.

## 후원 목록 (영상 후원 관리)

**[대시보드] → 방송 도우미** 오른쪽 위에서 들어온 후원을 표로 모아 봅니다.

- 시간 · 종류(영상/채팅) · 닉네임 · 금액 · 내용(영상 후원이면 **영상 제목**)
- 줄마다 **대기 / 봄 / 넘김** 표시 (더블클릭: 대기 ↔ 봄, 여러 줄 한 번에 가능) → 영상 대기열처럼 관리
- 영상만 / 채팅만 / 대기만 골라 보기, 합계 금액, 대시보드 버튼에 대기 건수 표시
- **프로그램을 켜면 후원 받기가 자동으로 시작**됩니다. (로그인돼 있을 때) 창을 안 열어도 기록되고, 대시보드 버튼에 대기 건수가 표시됩니다.
  끄려면 **[방송 관리] → ③ 채팅 → '프로그램을 켜면 후원 받기 자동 시작'** 체크 해제 (그때는 채팅창 / 후원 목록 창을 열었을 때만 받음)
- 채팅창과 **같은 연결 하나**를 나눠 씁니다.
- 받은 후원은 **`data/donations.json` 에 저장**돼서, 프로그램을 껐다 켜도 목록과 봄 / 넘김 표시가 그대로 남습니다.
  예전 후원은 시간 칸에 날짜도 함께 보이고, **'오늘만 보기'** 로 오늘 것만 볼 수 있습니다. (최근 3000건까지 보관)
- 치지직 공식 API 에는 지난 후원 내역을 가져오는 기능이 없어서, **프로그램이 꺼져 있던 동안의 후원은 가져올 수 없습니다.**

### 테스트 도구 (후원 목록 → [테스트 도구])

| 기능 | 하는 일 |
|---|---|
| ① 가짜 후원 · 채팅 보내기 | 영상 / 채팅 / 미션 후원, 채팅 한 줄. 내 프로그램에서만 보이고 **'(테스트)'** 표시, 파일에 저장 안 됨 |
| ② 실패 상황 흉내 | 후원 권한 없음(403) · 연결 끊김 → 다시 연결 · 연결 오류 · 로그인 풀림. **[원래 상태로]** 로 되돌림 |
| ③ 실제 연결 점검 | 치지직에 진짜로 접속해서 로그인 → 접속 주소 → 채팅 받기 → 후원 받기 를 단계별 [성공] / [실패] 로 보여줌 |

> 치지직 공식 API 는 영상 후원의 **제목만** 알려주고, 영상 주소나 재생 제어(건너뛰기 · 정지) 기능은 없습니다.
> 영상 재생 · 건너뛰기는 **치지직 스튜디오**에서 해야 합니다. (창의 [치지직 스튜디오 열기] 버튼)
> 필요한 권한: `후원 조회`

## 유튜브 채팅 같이 보기 (공식 YouTube Data API)

치지직 + 유튜브 동시 송출할 때, 방송 도우미 채팅창에 **유튜브 채팅도 [YT] 로 섞어서** 보여줍니다.
**슈퍼챗**은 노란 줄 + 후원 목록('유튜브') 에 들어가고, "미션" 으로 시작하면 미션으로도 등록됩니다.

### API 키 발급 (한 번만, 무료)
1. <https://console.cloud.google.com> 에 구글 계정으로 로그인 → 위쪽에서 **새 프로젝트** 만들기
2. **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키** → 만들어진 키 복사
4. (권장) 키 → **API 제한사항** 에서 `YouTube Data API v3` 만 허용
5. 프로그램 **[설정] → 유튜브 → API 키** 에 붙여넣고 **[저장]**

구글 계정 로그인 연동은 필요 없어요. (공개 방송 채팅은 API 키만으로 읽을 수 있어요)

### 쓰는 법
- 방송 도우미 채팅창 위의 **[YT] 칸** 에 **유튜브 방송 주소**(예: `https://www.youtube.com/live/xxxxxxxxxxx`)를 넣고 **[유튜브 연결]**
  - `@채널이름` 만 넣어도 지금 방송 중인 영상을 찾지만, 찾는 데 사용량 100점이 들어서 **방송 주소를 넣는 걸 추천**해요.
- 마지막에 넣은 주소는 기억해 둬요. 방송 도우미 창을 닫으면 유튜브 연결도 끊겨요. (사용량 아끼기)
- 유튜브로 채팅 **보내기** 는 안 돼요. (구글 계정 로그인 연동이 필요해서 빠져 있어요)

### 하루 사용량 (중요)
- 구글 프로젝트마다 **하루 10,000점**, 채팅을 한 번 가져올 때 **5점**. 한국 시간 **오후 4~5시쯤** 다시 채워져요.
- **[설정] → 채팅 가져오는 간격** (기본 8초 ≈ 하루 약 4시간). 짧을수록 빨리 보이지만 빨리 바닥나요.
- 채팅창의 유튜브 줄에 **오늘 사용량** 이 보여요. 다 쓰면 이유가 빨갛게 표시되고 연결이 멈춰요.
- 방송이 더 길면 Google Cloud 에서 **할당량 증가 신청**(무료)을 할 수 있어요.

## 알아두면 좋은 점

- **방송 상태 조회 방식**: 공식 Open API 에는 "특정 채널의 방송 상태"를 바로 주는 엔드포인트가 없습니다.
  그래서 치지직 웹사이트가 쓰는 비공식 `live-detail` 주소를 1순위로 쓰고, 실패하면 공식 `/open/v1/lives`
  목록(시청자 순)을 5페이지(100개)까지 뒤져서 찾습니다. 비공식 주소는 예고 없이 바뀔 수 있으며,
  그 경우 시청자 수가 적은 방송은 "방송 꺼짐"으로 잘못 보일 수 있습니다.
- **방송 설정 변경**은 치지직의 '기본 방송 설정'을 바꾸는 것으로, 방송 중이면 현재 방송에도 반영됩니다.
- 스팀 API 는 하루 호출 횟수 제한이 있으니 자동 새로고침 간격은 10초 이상(기본 30초)을 권장합니다.
