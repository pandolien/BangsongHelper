# 방송 도우미 (BangsongHelper)

> 이 프로그램은 **치지직(CHZZK) · 네이버 · 스팀의 공식 프로그램이 아닌** 개인이 만든 비공식 도구입니다.
> 치지직 공식 Open API 를 사용합니다. (방송 상태 확인에만 치지직 웹사이트 주소를 먼저 써요 — 예고 없이 바뀔 수 있음)

치지직 스트리머를 위한 방송 도우미입니다. 켜면 **실시간 채팅 · 후원 목록 · 미션 타이머**가 한 화면에 바로 보이고,
지금 하는 게임(스팀 · 실행 중인 프로그램)에 맞춰 방송 카테고리를 자동으로 바꿔 줍니다.

---

## 1. 설치 방법

1. 이 저장소를 내려받습니다.
   - 깃허브 화면의 **Code → Download ZIP** 으로 받아 압축을 풀거나
   - `git clone https://github.com/pandolien/BangsongHelper.git`
2. 받은 폴더 안의 `install.bat` 을 더블클릭합니다.
   - 파이썬(없으면 자동 설치) → 가상환경(`.venv`) → 라이브러리 설치가 진행됩니다.
   - 처음 한 번만 하면 됩니다.

## 2. 실행 방법

`run.bat` 을 더블클릭하면 프로그램이 켜집니다.

### 업데이트 (설정은 그대로 두고 프로그램만 새로)
`update.bat` 을 더블클릭하면 새 버전을 내려받아요. **내 설정(`data/init.json`) · 후원 · 미션 기록 · Log 는 그대로 남아요.**
- `git clone` 으로 받은 폴더에서만 돼요. (zip 으로 받았다면 새 폴더에 받아서 켜면, 이전 설정을 이어받을지 물어봐요)
- 끝난 뒤 `run.bat` 으로 켜면, 새 버전으로 처음 켰을 때 바뀐 점을 한 번 보여줘요.
(설치를 안 했으면 `install.bat` 이 자동으로 먼저 실행됩니다.)

**시험용 설정으로 켜기** — 진짜 키 대신 시험용 계정 · 키를 쓰고 싶을 때:

| 명령 | 읽는 설정 파일 |
|---|---|
| `run.bat` | `data/init.json` (기본) |
| `run.bat --test` | `data/init_test.json` (없으면 빈 양식으로 새로 만들어요) |
| `run.bat --config 이름.json` | `data/이름.json` |

- 시험용 설정으로 켜면 창 제목과 맨 위에 **[테스트 설정]** 표시가 떠요.
- 후원 · 미션 · 유튜브 사용량 기록도 `donations_test.json` 처럼 **따로** 저장돼서 진짜 기록에 섞이지 않아요. (게임 짝 목록은 같이 써요)
- 터미널 명령도 똑같이 붙여요: `run.bat --test status`

**새 버전으로 옮길 때 — 이전 설정 이어받기**

새 버전을 새 폴더에 풀면 키 · 로그인 · 설정이 비어 있어요. 이전 버전의 `data/init.json` 을 그대로 가져올 수 있어요.

| 방법 | 어떻게 |
|---|---|
| 켜면 자동으로 물어봐요 | 설정이 **비어 있을 때만**, 옆에 있는 폴더에서 키가 들어 있는 `data/init.json` 을 찾아서 [가져오기] / [이번엔 건너뛰기] / [다시 묻지 않기] 를 물어봐요. (이미 키 · 로그인이 있으면 묻지 않아요) |
| 직접 고르기 | [설정] → **이전 설정 가져오기...** → 이전 폴더의 `data/init.json` 선택 |
| 터미널 | `run.bat import-config "이전폴더\data\init.json"` |

- 이어받는 것: 치지직 Client ID · Secret · 로그인, 스팀 · 유튜브 키, 서버 주소, 색상 등 프로그램 설정. 새 버전에서 새로 생긴 칸은 기본값으로 채워요.
- 지금 설정은 `data/init.json.bak` 으로 백업해요. 이전 폴더의 파일은 건드리지 않아요.
- 가져온 뒤에는 프로그램이 종료돼요. `run.bat` 을 다시 실행하면 적용돼요.
- 시험용 설정(`run.bat --test`)으로 켰을 때는 묻지 않아요.
- 후원 · 미션 기록과 게임 짝 목록은 가져오지 않아요. 필요하면 이전 폴더의 `data` 안 파일을 직접 복사하세요.

## 3. 사용 방법

### 처음 설정 (한 번만)

프로그램 위쪽 **[설정] 메뉴 → 키 · ID · 서버 주소** 에 아래 값을 넣고 **저장**합니다.

| 항목 | 받는 곳 |
|---|---|
| 스팀 API 키 | <https://steamcommunity.com/dev/apikey> (도메인 칸에 `localhost`) |
| SteamID64 | 스팀 프로필 주소 뒤의 17자리 숫자 (프로필 · 게임 세부 정보를 **공개**로) |
| 치지직 Client ID / Secret | <https://developers.chzzk.naver.com> → 애플리케이션 등록<br>로그인 리디렉션 URL: `http://localhost:8080/callback`<br>⚠️ 앱 ID · 이름에 `chzzk` · `치지직` · `naver` · `네이버` 를 넣으면 등록이 안 되거나 정지될 수 있어요 |
| 치지직 채널 ID | 내 방송국 주소 `chzzk.naver.com/` 뒤의 32자리 |
| 유튜브 API 키 (선택) | <https://console.cloud.google.com> → `YouTube Data API v3` 사용 → API 키 만들기 |
| 유튜브 방송 주소 (선택) | 동시 송출할 때 내 유튜브 방송 주소 (`https://www.youtube.com/live/...`). 저장한 뒤 채팅 위 **[유튜브 연결]** |

그다음 맨 위 **[치지직 로그인]** 을 눌러 브라우저에서 동의하면 제목 · 카테고리 변경, 채팅 기능을 쓸 수 있습니다.

> 치지직 개발자 센터 → 내 앱 → **[API scope 선택]** 에서 아래를 체크해야 합니다.
> 채널 정보 조회 · 방송 설정 조회 · 방송 설정 변경 · 채팅 메시지 조회 · 채팅 메시지 쓰기 · 채팅 공지 쓰기 · 활동제한 쓰기 · 활동제한 조회 · **후원 조회** · 구독 조회(구독 알림용)
> (**방송 스트림키 조회**는 프로그램이 쓰지 않으니 체크하지 않는 걸 권장해요)
> 권한을 추가했다면 **로그아웃 → 다시 로그인** 해야 적용됩니다.

> **주의:** 입력한 키 · 토큰은 `data/init.json` 에 저장됩니다. 이 파일은 남에게 보여주거나 깃허브에 올리면 안 됩니다.
> 소스 코드로 쓰는 경우, 키를 넣은 뒤 한 번 아래 명령을 실행해 두세요. (이 PC 에서 이 파일 변경을 git 이 무시)
>
> ```
> git update-index --skip-worktree data/init.json
> ```

### 화면(GUI)

켜면 **채팅 · 후원 목록 · 미션**이 바로 보입니다. (경계선을 끌어서 크기 조절)

| 위치 | 하는 일 |
|---|---|
| 맨 위 | 방송 상태 · 시청자 · 로그인 · 지금 게임 (색 딱지), 방송 제목 · 카테고리, 새로고침 |
| 왼쪽 | 실시간 채팅 (닉네임을 누르면 임시 제한 · 가리기, 치지직 이모티콘은 그림으로 표시 — 저장하지 않고 메모리에서만 사용) |
| 오른쪽 위 / 아래 | 후원 목록 / 미션 · 타이머 |
| 맨 아래 | 마지막 로그 한 줄 |

나머지는 메뉴에서 엽니다.

| 메뉴 | 들어 있는 것 |
|---|---|
| 방송 | 방송 관리 (제목 · 카테고리 · 공지), 지금 게임으로 카테고리 맞추기, 새로고침(F5), 로그인 · 로그아웃 |
| 보기 | 방송 상태 (치지직 · 스팀 자세히), 게임 짝, 로그 |
| 설정 | 키 · ID · 서버 주소, 색상 (라이트 · 다크 · 치지직 그린, 색 하나씩 바꾸기) |

### 터미널(CLI)

| 명령 | 하는 일 |
|---|---|
| `run.bat status` | 스팀 + 치지직 상태 한 번 출력 |
| `run.bat watch --interval 30` | 30초마다 계속 출력 (Ctrl+C 종료) |
| `run.bat login` / `run.bat logout` | 치지직 계정 연동 / 해제 |
| `run.bat setting` | 내 방송 설정 보기 |
| `run.bat set-title "새 제목"` | 방송 제목 변경 |
| `run.bat set-category "발로란트"` | 카테고리 검색 후 첫 결과로 변경 |
| `run.bat chat "안녕하세요"` | 채팅 전송 (최대 100자) |
| `run.bat notice "공지 내용"` | 채팅 공지 등록 |
| `run.bat sync-game` | 지금 하는 게임으로 카테고리 맞추기 |
| `run.bat game-map` | 게임 짝 목록 보기 |
| `run.bat game-map-add 2622380 "나이트레인" --memo "메모"` | 게임 짝 추가 / 수정 (gameid 자리에 exe 이름도 가능) |
| `run.bat game-map-remove 2622380` | 게임 짝 삭제 |
| `run.bat import-config "D:\이전폴더\data\init.json"` | 이전 버전의 설정 파일을 지금 설정으로 가져오기 (아래 참고) |

## 5. 기능

- **채팅 먼저 보이는 한 화면** — 실시간 채팅 + 후원 목록 + 미션을 메인 화면에, 항상 위 고정 가능. 나머지 화면은 메뉴에서
- **상태 보기** — 방송 켜짐 여부 · 제목 · 카테고리 · 시청자 수 · 지금 게임을 맨 위 색 딱지로 (자동 새로고침)
- **방송 설정 변경** — 방송 제목 · 카테고리 변경, 채팅 전송, 채팅 공지 등록
- **카테고리 자동 맞추기** — 지금 하는 게임(스팀 또는 실행 중인 프로그램)으로 치지직 카테고리 자동 변경
  - 짝 목록에 인기 게임 105개 기본 포함, 없으면 한국어 이름으로 자동 검색, 그래도 없으면 '종합 게임'
  - 스팀 밖 게임(롤 · 발로란트 · 메이플 등)도 감지, 게임이 아닌 스팀 프로그램(Wallpaper Engine, OBS 등)은 무시
- **실시간 채팅** — 스트리머 · 매니저 표시, 닉네임 색, 후원 강조, 자동 재연결, 바로 채팅 보내기
- **채팅 복사** — 채팅 위 [복사] (고른 글자, 없으면 전체) · 채팅 줄 우클릭 → 채팅 내용 복사 / 닉네임 + 채팅 복사 / 닉네임 복사
- **시청자 관리** — 임시 제한 / 활동 제한 / 메시지 가리기 / 제한 목록에서 풀기
- **시청자 정보** — 닉네임 → [이 시청자 정보 보기...]: 활동 제한 여부 · 구독 여부(티어 · 개월), 이 프로그램으로 한 제한 기록, 이 프로그램이 받은 그 시청자의 채팅. (치지직 공식 API 에 시청자의 지난 채팅 · 임시 제한 이력이 없어서, 프로그램이 켜진 뒤 받은 것과 이 프로그램으로 한 것만 보여요. 팔로워 여부는 목록이 커서 뺐어요)
- **치지직 리모컨 패널** — 메인 화면 오른쪽에 치지직 스튜디오의 리모컨 화면(`studio.chzzk.naver.com/채널ID/remotecontrol`)을 띄워요. 처음 한 번 네이버 로그인을 하면 다음부터는 자동으로 로그인돼요. (아이디 · 비밀번호는 저장하지 않아요) 화면 안의 버튼은 사람이 눌러요. [✕] 로 숨기고 [보기] 메뉴에서 다시 켤 수 있어요
  - 로그인 정보는 프로그램 폴더가 아니라 `%LOCALAPPDATA%\BangsongHelper\web_profile` 에 저장돼요. 지우려면 패널의 [로그아웃]
  - 네이버 주소만 패널 안에서 열고, 다른 사이트 링크는 기본 브라우저로 열어요
- **후원 목록 · 미션 화면** — 기본은 숨겨져 있어요. [보기] → "후원 목록 · 미션 화면 보이기" 로 켤 수 있어요. 숨겨도 후원 받기 · 소리 알림 · 미션 타이머는 계속 돌아요
- **OBS 채팅 화면** — [보기] → "OBS 채팅 화면 켜기" 를 체크하면 내 컴퓨터 안에서만 열리는 채팅 주소(`http://127.0.0.1:8765/chat`)가 생겨요. [보기] → "OBS 채팅 주소 복사" 로 복사해서 쓰세요
  - **방송 화면에 채팅 띄우기**: [보기] → "OBS 방송 화면용 채팅 주소 복사" → OBS 소스 [+] → **브라우저** → 붙여넣기 (보기 전용, 배경 투명)
  - **OBS 창 안에 붙이기 (스트리머만 봐요)**: [보기] → "OBS 독 주소 복사 (채팅 · 제목 입력 + 방송 상태)" → OBS 메뉴 [독] → **사용자 지정 브라우저 독** → 붙여넣기. 주소는 `http://127.0.0.1:8765/dock` 이에요 (= `/chat?input=1`). 한 패널에 이렇게 나와요. **방송 화면용 소스에는 이 주소를 쓰지 마세요**(시청자에게 입력칸이 보여요)
    - **맨 위 방송 상태**: ● 방송 중 / 시청자 수 / 카테고리 / 방송 제목 / 지금 하는 게임 / 치지직 로그인 여부 (프로그램이 새로고침할 때마다 갱신)
    - **가운데 채팅**: 채팅 · 후원 카드
    - **아래 제목 입력칸**: 새 제목을 쓰고 Enter 또는 [제목 변경] → 치지직 방송 제목이 바뀌어요 (100자 · 3초에 한 번)
    - **맨 아래 채팅 입력칸**: 채팅을 쳐서 보내요 (100자 · 1.5초에 한 번)
    - 제목 · 채팅은 **치지직 로그인**이 되어 있어야 해요. 안 되어 있으면 패널에 안내가 떠요
    - 주소 옵션 `status=0` (상태줄 숨김) · `title=0` (제목 입력칸 숨김). 예: `/chat?input=1&title=0`
  - 주소 뒤 옵션: `?theme=light` (밝은 글자색) · `size=24` (글자 크기) · `lines=20` (보이는 줄 수) · `time=1` (시간 표시) · `donation=0` (후원 카드 숨김) · `bg=solid` (어두운 배경) — `&` 로 이어 붙여요. 예: `/chat?size=24&lines=20`
  - 포트 번호는 `data/init.json` 의 `app.obs_overlay_port` (기본 8765)
  - 안전: 내 컴퓨터(127.0.0.1)에서만 열려요. 채팅 · 후원 내용만 내보내고 키 · 토큰은 보내지 않아요. 채팅 보내기는 켤 때마다 새로 만드는 비밀 표가 맞을 때만 받아서, 다른 웹사이트가 대신 채팅을 보낼 수 없어요
- **OBS 한 화면에 채팅 + 영상 후원** — 치지직 스튜디오의 **알림 주소**(방송용으로 OBS 브라우저 소스에 넣는 그 주소)를 [보기] → "OBS 영상 후원 알림 주소 설정..." 에 한 번 붙여넣으면, **OBS 채팅 화면 위쪽에 영상 후원 알림 화면이 같이** 나와요. OBS 브라우저 소스 하나로 끝나요
  - 주소 뒤 옵션: `altheight=55` (알림 화면 높이 %, 나머지 아래가 채팅) · `alert=0` (알림 화면 끄기). 예: `/chat?altheight=60`
  - 프로그램이 영상 주소를 받는 게 아니라, 치지직이 주는 알림 화면을 그대로 보여주는 거예요. (영상은 치지직 알림 화면이 재생해요)
  - 알림 주소에는 **내 채널의 비밀 값**이 들어 있어요. 남에게 보여주지 말고, `data/init.json` 에 저장되니 그 파일을 올리거나 보내지 마세요. 네이버(https) 주소만 받아요
  - 영상 후원의 재생 · 건너뛰기 버튼은 아래 리모컨 방법으로 눌러요
- **OBS에서 영상 후원 다루기** — [보기] → "OBS 리모컨(영상 후원) 주소 복사" 를 OBS **사용자 지정 브라우저 독** 에 붙이면 OBS 안에서 치지직 리모컨으로 재생 · 건너뛰기를 할 수 있어요. (처음 한 번 네이버 로그인) 영상 자체가 방송 화면에 나오는 건 치지직 스튜디오가 주는 **방송용 알림 주소**를 OBS 브라우저 소스로 쓰는 방식이에요. 이 프로그램은 영상 주소를 받지 못해서 대신 재생할 수 없어요. 영상 후원이 오면 채팅 화면에 `영상 후원 금액 닉네임` 카드로 나와요
- **업데이트 안내** — 새 버전으로 처음 켜면 바뀐 점을 한 번 보여줘요. ([보기] → 업데이트 안내 보기 로 다시 볼 수 있어요)
- **후원 목록** — 영상 · 채팅 후원 모아 보기, 대기 / 봄 / 넘김 표시, 합계, 껐다 켜도 기록 유지
- **알림 소리** — 후원은 부드러운 '도-미', 구독은 '솔-도-미' 로 소리가 달라요. 후원 소리 · 구독 소리를 따로 켜고 끄고, 미리 듣고, **크기(0~100%) · 음 높이(낮게/보통/높게)** 를 맞출 수 있어요 ([⚙] 또는 [설정] → 알림 소리...)
- **구독 확인** — 구독이 오면 채팅 노란 줄 + 후원 목록에 표시 (티어 · 개월 수), '구독만' 보기
- **미션** — "미션"으로 시작하는 후원 자동 등록 → [받기] → [성공] / [실패], 제한 시간 타이머, 시간 초과 알림, OBS 용 타이머 파일, 채팅 알림
- **유튜브 채팅 같이 보기** — 동시 송출 시 유튜브 채팅을 `[YT]` 로 섞어 보기, 슈퍼챗은 후원 · 미션으로
- **로그 파일** — `Log` 폴더에 날짜별로 기록, 오늘 포함 7일치만 보관 (후원 · 구독 · 미션 · 연결 · 오류)
- **색상 설정** — 라이트 · 다크 · 치지직 그린 색 묶음, 색 하나씩 직접 바꾸기 (채팅 칸 포함)
- **테스트 도구** — 실패 상황 흉내, 실제 연결 단계별 점검 (후원 테스트는 치지직 스튜디오의 테스트 후원으로)
